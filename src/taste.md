# Aesthetic and Interaction Taste

## The Vibe
Futuristic, spatial, and tactile. This is not just a website; it feels like a modern operating system. It should look like a workspace the user wants to live in.

## Motion Guidelines
*   **Fluidity over speed:** Animations should use spring physics. Instead of linear fade-ins, elements should scale and bounce slightly into place.
*   **Tactile Feedback:** Use Rive to make clicks feel physical. When a Stage Manager stack is clicked, it should visually compress before expanding into a window.
*   **Continuous Life:** The screen should never be completely still. The 3D character must have an idle breathing animation.

## AI and 3D Interaction Rules
*   **Show, don't just tell:** The AI should not just print text. The 3D character must react to the context of the conversation. If the AI is retrieving data about a coding project, the character should look like it is typing or thinking.
*   **Unobtrusive Chat:** The chat bubble should float organically near the character. It should not block the user's view of the project windows. 

## Language Guidelines
*   Use simple, direct language in the UI and the AI's programmed responses. 
*   Avoid complex metaphors. Use concrete examples of work and skills. 
*   Maintain a professional but conversational tone throughout the experience.
